📖 隨隨 使用說明書

🎭 1. 如何創建角色？

點擊右上方 🎭 角色設定 按鈕，可在彈窗中自訂「助手名字」、「頭像」、「聊天背景」、「背景模糊與透明度」、「系統提示詞（Prompt）」及「開場白」。設定完成後點擊「儲存」，可選擇「更新當前角色」或「另存為新角色」。您也可以直接點擊下方預設按鈕，快速新增「沐晨」或「奧丁」角色。

🧠 2. 如何更換模型？

點擊右上方 ⚙️ 設定 按鈕，在「模型名稱」下拉選單中可以自由切換不同版本的 Gemini 模型（例如：gemini-2.5-pro、gemini-3.5-flash 等），以適應不同的運算需求與速度。

🔑 3. 關於 API 金鑰與安全模式

同樣在右上方 ⚙️ 設定 彈窗中，輸入您的 Gemini API 金鑰。金鑰將安全地儲存在您本地瀏覽器的緩存中（LocalStorage），絕不會上傳至任何第三方伺服器。如果您想免金鑰分享給他人安全使用，可以在設定中填入您部署的 Vercel 伺服器網址，並將金鑰欄位留空。

🧹 4. 如何清除對話？

點擊右上方第一個 🧹 新對話 按鈕，確認後即可清空目前畫面的所有對話歷史，並以該角色的初始設定與開場白重新開始乾淨的對話。
